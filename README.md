# 每日英語聽力練習網站 (Daily English Listening Practice)

## 項目概述

這是一個專門設計的英語聽力練習網站，通過每日精選的Ted Talk影片和互動式選擇題，幫助用戶系統性地提升英語聽力能力。

## 主要功能

### ✅ 已完成功能

1. **分級學習系統**
   - 小學生級別 (5分鐘影片, 3題測試)
   - 中學生級別 (15分鐘影片, 5題測試)
   - 進階級別 (15分鐘影片, 5題測試)
   - IELTS考試準備 (15分鐘影片, 5題測試)
   - TOEFL考試準備 (15分鐘影片, 5題測試)

2. **智能影片推薦**
   - 根據難度級別自動選擇合適影片
   - 不同年齡層的內容分類
   - 考試導向的專業內容

3. **每日任務系統**
   - 每日自動生成15分鐘精選Ted Talk影片
   - 基於日期的任務管理
   - 任務完成狀態追蹤

4. **影片播放器**
   - 嵌入YouTube播放器
   - 影片資訊展示（標題、演講者、時長、分類）
   - 觀看進度標記功能

5. **互動式測試系統**
   - 3-5道選擇題測試理解程度（根據難度）
   - 即時答案選擇和反饋
   - 測試進度條顯示
   - 分數計算和結果展示

6. **學習進度追蹤**
   - 個人學習統計（總學習日數、完成任務、平均答對率）
   - 各級別完成情況統計
   - 本週完成率圓形進度條
   - 連續學習天數計算
   - 學習日曆視覺化

5. **數據管理**
   - 任務數據存儲結構
   - 題目數據管理
   - 用戶進度追蹤

6. **響應式設計**
   - 適配桌面、平板、手機設備
   - 現代化UI設計
   - 平滑動畫效果

## 技術架構

### 前端技術
- **HTML5 + CSS3 + JavaScript (ES6+)**
- **Bootstrap 5** - 響應式框架
- **Font Awesome** - 圖標庫
- **Google Fonts (Inter)** - 字體

### 數據存儲
- **RESTful Table API** - 本地數據存儲
- **表格結構**:
  - `tasks` - 任務數據
  - `questions` - 題目數據
  - `user_progress` - 用戶進度

### API端點
- `GET /tables/{table}` - 獲取數據列表
- `POST /tables/{table}` - 創建新記錄
- `PUT /tables/{table}/{id}` - 更新記錄
- `DELETE /tables/{table}/{id}` - 刪除記錄

## 使用說明

### 基本使用流程

1. **開始每日任務**
   - 訪問網站主頁
   - 點擊「開始今日任務」按鈕
   - 系統自動加載當日影片和題目

2. **觀看影片**
   - 觀看15分鐘精選Ted Talk影片
   - 可以點擊「標記為已觀看」繼續下一步

3. **完成測試**
   - 回答5道選擇題
   - 可以前後切換題目
   - 完成後查看分數和反饋

4. **查看進度**
   - 在「學習進度」頁面查看統計數據
   - 追蹤本週完成率和連續學習天數

### 功能入口

- **主頁**: `/index.html` - 網站入口和介紹
- **每日任務**: `#daily-task` - 當日學習任務
- **學習進度**: `#progress` - 個人學習統計
- **關於**: `#about` - 網站介紹
